# Desenvolvimento do Myths' Valley 3D

Em 01/10/2026, o autor decidiu manter os jogos 2D e 3D em repositórios
independentes. O projeto 3D está na raiz de `acentauric/myths-valley-3d`.

As regras, interfaces e dados já incorporados pertencem a este projeto.
Nenhum comando de desenvolvimento ou teste exige o checkout do jogo 2D.

O planejamento vigente está em [PLANO.md](PLANO.md). As etapas anteriores e
suas decisões estão no [registro histórico](HISTORICO_DESENVOLVIMENTO_3D.md).
