Cursor do vale

Cinco propostas desenhadas em SVG para substituir a seta e a mão em ouro de hoje. Cada uma parte de uma peça do enredo ou da identidade Crônica do Recôncavo. Nas áreas de teste o navegador usa o cursor de verdade, no tamanho do jogo; os botões mostram o estado de clique.

Corredor de comparação

Arraste o mouse de uma coluna para outra: o fundo é o mesmo, só o cursor troca. Passe pelo botão para ver o clique.

As propostas

À esquerda de cada prévia, sobre a laca; à direita, sobre céu claro. A faixa de baixo mostra o tamanho real em fundos do jogo.

  • O cursor atual é o PNG do jogo (40 px fixos), por isso não muda com o seletor de tamanho.
  • O ponto quente (onde o clique acontece) de cada proposta fica na ponta: agulha, bico da pena, fisga, anzol, dedo.
  • Os PNGs baixados aqui já servem para teste no Godot em tela.gd; a versão final sairia de um gerador como o atual, tools/prototipo_3d/cursor/gerar_cursor.py.
